## AI Change Logging

Every change made by an AI agent **must** be logged in `/docs/ai-logs/` in JSONL format.

### Log Entry Template

```json
{"id": 1, "timestamp": "2026-10-09T18:33:52.515+01:00", "summary": "Created AGENTS.md file", "files": [".ai/AGENTS.md"], "explanation": "Initialized the AI instructions file with repository structure and action definitions"}
```

### Logging Rules

- **Sequential IDs**: Each log entry gets a sequential integer ID (1, 2, 3, ...).
- **Timestamp**: ISO 8601 format with timezone offset.
- **Summary**: A short (one-line) summary of the change.
- **Files**: Array of file paths that were modified or created.
- **Explanation**: A brief explanation of what was changed and why.
- **Per-File Logging**: Every file modified or created must have its own log entry. Do not group multiple files into a single log entry.

### Log File Naming

Log files are named: `YYYY-MM-DD.jsonl` (e.g., `2026-10-09.jsonl`).

## Actions

Actions are commands that AI agents can execute. Each action has a name, a command trigger, and an execution specification.

### Action: Store Prompt Session

- **Name**: `Generate the prompts evidences`
- **Command**: `/store-prompt-session`
- **Execution**:
  1. Create a new file in `/docs/ai-prompts/`
  2. Filename format: `YYYY-MM-DD.HHMMSS.md`
  3. Use the template below:

```markdown
# PROMPT
{Full transcript of the entire session — every user prompt and every AI response, verbatim. Do not summarize or interpret. Transcribe exactly what was said.}

# Model
{Specific model used during the session}

# Summary
{Create a summary of the session, the main points (in bullets), files created/modified short explanations of the reasons. Add a session on Disagreements of the User based on your interpretation.}

# Critical Thinking (User Space about the Session)
{empty}
```

4. The `# PROMPT` section must contain the **full verbatim transcript** of the entire session — every user message and every AI response, in order. Do not summarize, interpret, or paraphrase. Transcribe exactly what was said.

## Behaviors

1. **Always log changes**: Every file modification by an AI agent must be recorded in the JSONL log.
2. **Store prompts**: Every user prompt session must be saved in `/docs/ai-prompts/`.
3. **Follow structure**: Never create files outside the defined structure unless explicitly instructed.
4. **Be precise**: Make surgical, complete changes. Avoid unrelated modifications.
5. **Validate**: Run existing linters, builds, and tests after changes.
6. **Document**: Update related documentation when making structural changes.

## Workflows

### Standard Development Workflow

1. Receive task from user
2. Store the prompt session (`/store-prompt-session`)
3. Make changes to `src/` or `tests/`
4. Log all changes (`/docs/ai-logs/`)
5. Run tests and linters
6. Update documentation if needed
7. Report results to user

### Repository Initialization Workflow

1. Execute `/initialize-repo`
2. Verify all folders exist
3. Verify `README.md` is updated
4. Log the initialization in `/docs/ai-logs/`
